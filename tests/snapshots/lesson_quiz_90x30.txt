│ ★ programar. Precisa de paciência, precisão e curiosidade — três coisas que            │
│ ★ todo mundo tem.                                                                      │
│                                                                                        │
│Toda linguagem de programação oferece um pequeno conjunto de ferramentas:               │
│                                                                                        │
│  · GUARDE informações (variáveis)                                                      │
│  · DECIDA entre caminhos (condições)                                                   │
│  · REPITA tarefas (laços)                                                              │
│  · ORGANIZE passos reutilizáveis (funções)                                             │
│                                                                                        │
│O resto — aplicativos, jogos, sistemas — é combinação dessas quatro peças.              │
│Neste curso, você vai dominar cada uma delas em Rust.                                   │
│                                                                                        │
