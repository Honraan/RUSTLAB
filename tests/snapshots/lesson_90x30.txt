│Programar é escrever, com palavras muito precisas, uma sequência                        │
│de instruções que uma máquina executa. Um programa é como uma receita:                  │
│cada passo deve estar claro, na ordem certa, sem espaço para ambiguidade.               │
│                                                                                        │
│A máquina não "adivinha". Se você diz "misture um pouco", ela pergunta                  │
│(metaforicamente): quanto é um pouco? Programar é aprender a responder                  │
│essas perguntas com antecedência.                                                       │
│                                                                                        │
│ ★ Você não precisa saber matemática avançada nem inglês perfeito para                  │
│ ★ programar. Precisa de paciência, precisão e curiosidade — três coisas que            │
│ ★ todo mundo tem.                                                                      │
│                                                                                        │
